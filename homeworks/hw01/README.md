## Folders

`instructions/` contains the assignment PDF provided by the instructor.

`data/` contains the Moneyball datasets:

- `moneyball-training-data.csv`
- `moneyball-evaluation-data.csv`

`notebooks/` contains the single R or Python notebook used for the complete homework analysis.

The notebook, `hw01_moneyball_analysis.ipynb`, will cover the full workflow: understanding the datasets, preparing the variables, building the multiple linear regression model, evaluating it, and generating predictions.

`report/` contains figures and the final PDF submitted for the assignment.

## Notebook workflow

Save all HW01 work in `notebooks/hw01_moneyball_analysis.ipynb`. Select the R or Python kernel, run the analysis from the first cell through the last cell, check the results, and export the completed notebook as a PDF into `report/`.
